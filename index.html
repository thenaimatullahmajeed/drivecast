You decide what connects.

The operator configures a specific source and target channel. DriveCast verifies the channel ID before real uploads and processes videos oldest first.

Separate clients

Each client has a private GitHub repository, credentials and schedule. Drive and YouTube can be authorized by different Google accounts.

Conservative recovery

Files or records left in Processing, Failed or Needs review are held for manual review. Uncertain uploads are never automatically started again.

A small daily queue

Public posting on discovery, with configurable source checks and a daily attempt limit (default two). Failed/uncertain attempts also use a slot.

What this website does

This is DriveCast’s public information and policy website. Account connection happens in the operator’s local setup panel; scheduled video processing runs in private GitHub Actions repositories. This website does not accept Google credentials or video uploads.

Google authorization and any required verification must be completed before unattended operation. Publishing this website does not establish Google approval.

Access with your consent

Google Drive access reads and organizes queued files. The optional official Meta connection scans supported public professional media. YouTube upload access sends videos, while read-only channel access verifies the destination and reads available counters. Access can be revoked in the relevant platform settings.
