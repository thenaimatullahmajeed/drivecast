Operator guide

One setup.
Separate client queues.

This website provides public app information and policy pages for DriveCast. The Python setup panel runs locally. After authorization and deployment, scheduled uploads run in a separate private GitHub Actions repository for each client.

1. Configure Google Cloud

In the same project, enable Google Drive API and YouTube Data API v3. Configure Google Auth Platform Branding, Audience and Data Access, then create an OAuth client of type Desktop app and download its JSON file.

Required scopes are https://www.googleapis.com/auth/drive, https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.readonly. Drive authorization and YouTube authorization happen separately.

3. Verify ownership if Google requests it

Google may require proof that the project owner controls the website. In Google Search Console, sign in with the Google account that owns the Cloud project and add a URL-prefix property for the complete homepage URL above. Select the HTML tag or HTML file verification method. The returned verification tag/file can be added to this website’s repository, followed by Verify in Search Console. Do not substitute a placeholder tag.

If Google’s review requires a domain you own rather than a shared hosting subdomain, use a custom domain with GitHub Pages, verify that domain and update all branding URLs together. Hosting can stay on GitHub Pages; domain registration is separate.

4. Authorize each client

In the local setup panel, enter the client name, matching Drive folder/channel names, folder link and channel link. Select the Desktop JSON. Approve Drive first using a regular Google account with editor access to the folder. Approve YouTube second, choosing the intended channel or Brand Account. The two Google accounts can differ.

Deploy the client’s private repository, review the dry run, run one private test, check the actual video in the intended YouTube Studio channel, then enable the schedule. Do not put Google credentials into this public website repository.

5. Ongoing operation

Keep new videos directly in the chosen Drive folder. Scheduled starts vary around 4:15–4:25 PM and 8:15–8:25 PM New York time, plus runner, download, upload and processing delays. At most two attempts are reserved per day. Failed/Processing items require review; they are never automatically retried. The local computer can be switched off after automation is deployed and enabled.
