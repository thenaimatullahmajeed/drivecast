Operator guide

One local desk.
Separate client queues.

This is a public information website. The account-management panel stays on your laptop. Open setup.cmd from the tool folder; it prepares the local environment and opens the panel in Chrome.

1. Save connections and recovery

Create a Recovery Password of at least 12 characters and save it privately. In Connections, authorize each intended GitHub account at the official GitHub device page. Use trusted accounts: a repository's owner retains access to its client records and workflows. Set up the private recovery repository so Sync can checkpoint configuration, records and encrypted credentials.

2. Configure Google once, reuse the app

Select a Google Cloud project. Enable YouTube Data API v3 and, for Drive sources, Google Drive API. Configure Branding and Audience. Create a Desktop app OAuth client and download JSON.

In local Connections choose YouTube, select JSON, and approve the intended channel or Brand Account. For a Drive source, create a separate Drive connection using the same JSON and a normal Gmail with folder Editor access. The two Google accounts can differ. Existing APIs do not need enabling again for each new client using the same project.

Scopes are youtube.upload and youtube.readonly for YouTube, plus separately approved drive access for Drive. Testing access requires approved test users and can have short-lived refresh authorization. Production status, OAuth verification and the YouTube upload audit are separate; publishing this website does not grant Google approval or guarantee public API uploads.

4. Optional Instagram source

The implementation uses Instagram API with Facebook Login / Business Discovery. Link your own Creator/Business Instagram account to a Facebook Page, create/configure a Meta app, then authorize the relevant read permissions using Graph API Explorer. Check permissions and expiry using Access Token Debugger.

Save the authorized Facebook User token in the local Meta connection. A supported public professional client's username can then be scanned through Business Discovery. The tool only queues video media for which the API supplies a usable download URL. Personal/private/inaccessible accounts and missing media URLs are not bypassed. Production access can require Meta review/verification. The current operator has not configured Meta yet, so the new integration awaits a real account test.

5. Add and verify a client

Choose Instagram OR Google Drive, the saved source connection, exact saved YouTube channel and GitHub account. Folder/channel names do not have to match; source/channel IDs govern routing. Validate and save, deploy paused, and review the dry run. Request one real private test, Sync its result, inspect the actual video in the correct YouTube Studio, then explicitly enable the schedule.

Instagram captions provide title/description. For Drive, a matching JSON sidecar takes priority; otherwise the first line of a matching TXT file supplies the title, with remaining lines as description. Otherwise the filename is used. Basic metadata requires no AI key.

6. Operation and a new laptop

Scheduled starts are near 4:15 PM and 8:15 PM New York time with a random 0–10 minute wait, plus provider delays. At most two reserved attempts per channel/day, including failures/tests. Uncertain records require manual review. Once deployed and enabled, eligible GitHub-hosted workflows can run while your laptop is off; the local panel itself stays offline.

Copy the tool folder or fetch the encrypted workspace from the private recovery repository. The original Recovery Password is required on a new laptop; revoked or expired platform authorization still requires reconnection. Legacy Google tokens stored only in write-only GitHub Secrets need one reconnect to become part of portable encrypted recovery. Sync tests connections and imports records without uploading videos.
