# DriveCast public information website

Public homepage, privacy policy, terms and setup guide. These files contain no OAuth credentials, client configuration or uploader runtime.

Intended hosting: GitHub Pages, repository `thenaimatullahmajeed/drivecast`, root directory of the repository default branch.

Homepage: https://thenaimatullahmajeed.github.io/drivecast/

Google's OAuth production/verification and website ownership requirements are separate from deployment. The setup guide explains Search Console URL-prefix verification and the custom-domain fallback if Google requires it. Hosting alone does not establish Google approval or promise permanent availability.

The local Python setup panel and client upload workflows are separate private components. Do not upload their work directories, Google JSON files, refresh tokens, client state or videos to this public repository.
